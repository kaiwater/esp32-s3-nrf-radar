# 2.4G 噪声/占用探测器（feat/2.4g-scan）

**状态：已实现并实机扫描。** 当前由一个 NRF 扫 83 个信道；A 不在时自动用 B。

目标：用 NRF24L01 的 RPD 做协议无关的 2.4GHz 能量/占用扫描，帮助定位
OpenWrt 报告里“比其他房间高约 10dBm”的噪声源。

## 原理与限制

- NRF24L01 的 `RPD` 是 1-bit 载波检测，门限约 **-64dBm**
- 不关心协议：WiFi、图传、蓝牙、噪声都算“有能量”
- 扫描 0–82 信道（2400–2482MHz），1MHz 步进
- 每信道采样 16 次 RPD（每次 500µs），得到 0–100% 占用
- K3 采一次安静环境的基线；之后显示 `current - baseline` 的正偏差
- **不是 dBm，也不是频谱仪**；只能看占用/相对变化
- 需要具体带宽/波形时，用 ESP32-S3 SDR 的 FFT/瀑布

## UI

```
2.4G  SCAN            0-82
[ 80 列占用柱状图 ]
PEAK 2437 +35         DLT
SCAN 12               BASE
[ 7 行 x 80 列瀑布 ]
```

- 柱高：绝对占用或相对基线的正偏差
- `PEAK`：当前最强信道与数值
- `DLT/ABS`：当前模式
- `BASE`：是否已有基线
- 瀑布：每次扫描追加一行

## 操作

| 按键 | 功能 |
|---|---|
| K1 | ABS / DELTA 切换 |
| K2 | 清空瀑布历史 |
| K3 | 采基线（之后自动进 DELTA） |
| K4 | 暂停 / 继续 |
| 长按 K3 | 切换配色 |
| 长按 K4 | 重启 ESP32 |

## 文件

- `main/scan_view.h`：扫描视图数据
- `main/scanner.c/.h`：NRF 扫描、基线、瀑布
- `main/st7735.c`：`st7735_draw_scan()`
- `main/main.c`：切到 scanner
